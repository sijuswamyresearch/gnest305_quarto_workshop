GNEST305: Introduction to AI & Data Science

Two-Day Interactive Practical Workshop for Semester S3 B.Tech (Artificial Intelligence)

Welcome to the 2-Day Interactive Workshop

This interactive Quarto website is designed for Semester S3 B.Tech Artificial Intelligence students taking GNEST305: Introduction to Artificial Intelligence and Data Science (4 Credits, L:T:P:R = 3:1:0:0).

Instead of treating Linear Algebra, Probability & Statistics, Machine Learning, and Data Science Workflows as isolated theoretical silos, we connect all four syllabus modules through two continuous, hands-on data threads running directly in your browser via quarto-live (pyodide):

  1. Primary Thread: Iris Botanical Dataset — A clean 4-feature, 150-sample dataset (sepal_length, sepal_width, petal_length, petal_width) used to build geometric and mathematical intuition from first principles.
  2. Engineering Practice Thread: Industrial Motor Predictive Maintenance — A realistic 4-sensor engineering dataset (vibration_mm_s, temperature_c, current_amp, acoustic_db) across 3 operating states (Normal, Bearing_Wear, Overheating_Fault) where you apply the exact same mathematical pipelines to diagnose industrial machinery.

1 Two-Day Workshop Schedule (9 Hours Total)

1.1 Day 1: Data Representation & Geometric Foundations (4.5 Hours)

Time Session GNEST305 Module Core Math & Algorithms Hands-On Python Lab
09:00 – 11:00 (2.0 hrs) Session 1: The Data Science Pipeline Module 4 (Basics of Data Science) Data matrices \(X \in \mathbb{R}^{n \times d}\), feature distributions, Big Data vs. Data Science, modeling lifecycle Interactive EDA, statistical profiling & visualization on Iris \(\rightarrow\) Practice on Motor Sensors
11:00 – 11:15 Break — — —
11:15 – 13:45 (2.5 hrs) Session 2: Linear Algebra & Dimensionality Reduction Module 2 (Mathematical Foundations) Covariance matrix \(\Sigma\), Spectral Decomposition (\(\Sigma = Q\Lambda Q^T\)), Singular Value Decomposition (\(X = U S V^T\)), PCA projection Implementing SVD & PCA from scratch in numpy on Iris (4D \(\rightarrow\) 2D) \(\rightarrow\) Compressing 4D Sensor Data

1.2 Day 2: Statistical Inference, Machine Learning & Neural Networks (4.5 Hours)

Time Session GNEST305 Module Core Math & Algorithms Hands-On Python Lab
09:00 – 11:15 (2.25 hrs) Session 3: Applied Probability & Statistical Estimation Module 3 (Probability & Statistics) Random variables, MLE (\(\hat{\mu}, \hat{\sigma}^2\)), Bayes’ Theorem \(P(Y|X)\), Pearson Correlation \(r\), Ordinary Least Squares (OLS) Gaussian MLE, Gaussian Naive Bayes classifier & OLS regression on Iris \(\rightarrow\) Sensor degradation & fault probability
11:15 – 11:30 Break — — —
11:30 – 13:45 (2.25 hrs) Session 4: Machine Learning & Deep Neural Networks Module 1 (Intro to AI & ML) Supervised vs. Unsupervised, K-Means, Logistic Regression (\(\sigma(z)\)), Perceptron, Universal Approximation Theorem, MLP & Backprop K-Means, Logistic Regression, and Deep MLP (Regression + Classification) on Iris \(\rightarrow\) Full Predictive Maintenance Model

2 Syllabus Alignment & Course Outcomes (COs)

Course Outcome Description Bloom’s Level Workshop Coverage
CO1 Apply the concept of machine learning algorithms including neural networks and supervised/unsupervised learning techniques for engineering applications. K3 (Apply) Day 2, Session 4 (module1-ml-ann.qmd)
CO2 Apply advanced mathematical concepts such as matrix operations, singular values, and principal component analysis to analyze and solve engineering problems. K3 (Apply) Day 1, Session 2 (module2-linear-algebra.qmd)
