GNEST305 Module 2 — Data Matrices, Spectral Decomposition, SVD & Principal Component Analysis (2.5 Hours)

1 Why Linear Algebra is the Engine of AI

In Session 1, we saw that both the Iris dataset and Motor Sensor Telemetry live in a 4-dimensional vector space \(\mathbb{R}^4\) (\(150 \times 4\) matrix). How can we visualize a 4D (or 1,000D) dataset on a 2D screen while losing the least possible information?

The answer lies in Module 2 (Text-1: Gilbert Strang, Introduction to Linear Algebra): Matrix Decompositions and Principal Component Analysis (PCA).

  • Matrix Decomposition: Eigenvalues and Eigenvectors (\(Av = \lambda v\))

2 1. Mean-Centering and the Covariance Matrix \(\Sigma\)

Let \(X \in \mathbb{R}^{n \times d}\) be our standardized (or mean-centered) data matrix where each column has mean \(0\). The sample covariance matrix \(\Sigma \in \mathbb{R}^{d \times d}\) captures both the variance of each feature (diagonal entries) and the linear redundancy between features (off-diagonal entries):

\[\Sigma = \frac{1}{n - 1} X^T X\]

Notice two critical properties of \(\Sigma\): 1. \(\Sigma\) is a square \(d \times d\) matrix (\(4 \times 4\) for Iris and Motor sensors). 2. \(\Sigma\) is real and symmetric (\(\Sigma^T = \Sigma\)) and positive semi-definite (\(v^T \Sigma v \ge 0\)).

3 2. Spectral Decomposition (Eigendecomposition)

By the Spectral Theorem, any real symmetric matrix \(\Sigma \in \mathbb{R}^{d \times d}\) can be factored into an orthogonal matrix of eigenvectors \(Q\) and a diagonal matrix of real eigenvalues \(\Lambda\):

\[\Sigma = Q \Lambda Q^T = \sum_{i=1}^d \lambda_i q_i q_i^T\]

where: * \(q_1, q_2, \dots, q_d\) are mutually orthonormal eigenvectors (\(q_i^T q_j = \delta_{ij}\), so \(Q^T Q = I\)). Geometrically, these define the principal axes of variance of the data cloud! * \(\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_d \ge 0\) are the corresponding eigenvalues, which measure the exact variance of the data projected onto each axis \(q_i\).

4 3. Singular Value Decomposition (SVD)

What if we don’t even want to form \(X^T X\) (which can lose numerical precision)? Singular Value Decomposition (SVD) factors any rectangular matrix \(X \in \mathbb{R}^{n \times d}\) directly:

\[X = U S V^T\]

  • \(U \in \mathbb{R}^{n \times n}\): Orthogonal matrix of left singular vectors (columns are eigenvectors of \(X X^T\)).
  • \(S \in \mathbb{R}^{n \times d}\): Diagonal matrix of non-negative singular values \(\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_d \ge 0\).
  • \(V \in \mathbb{R}^{d \times d}\): Orthogonal matrix of right singular vectors (columns are eigenvectors of \(X^T X\)).

The Golden Bridge Connecting SVD, Spectral Decomposition, and PCA: Substitute \(X = U S V^T\) into the covariance formula \(\Sigma = \frac{1}{n-1} X^T X\): \[\Sigma = \frac{1}{n-1} (U S V^T)^T (U S V^T) = \frac{1}{n-1} V S^T U^T U S V^T = V \left(\frac{S^2}{n-1}\right) V^T\] Comparing this with \(\Sigma = Q \Lambda Q^T\), we see immediately that: 1. The right singular vectors \(V\) are identical to the spectral eigenvectors \(Q\) (the Principal Components!). 2. The eigenvalues \(\lambda_i\) of the covariance matrix are directly related to the singular values \(\sigma_i\): \[\lambda_i = \frac{\sigma_i^2}{n - 1}\]

5 4. Dimensionality Reduction via Principal Component Analysis (PCA)

To project our \(d\)-dimensional data matrix \(X \in \mathbb{R}^{n \times d}\) down to a \(k\)-dimensional subspace (\(k < d\), e.g., \(k=2\)), we simply multiply \(X\) by the first \(k\) columns of \(V\) (let’s call this \(W_k = V_{:, 1:k} \in \mathbb{R}^{d \times k}\)):

\[Z = X W_k \in \mathbb{R}^{n \times k}\]

And we can reconstruct the low-rank approximation \(\hat{X}_k \in \mathbb{R}^{n \times d}\) back in the original 4D space via:

\[\hat{X}_k = Z W_k^T = \sum_{i=1}^k \sigma_i u_i v_i^T\]

By the Eckart-Young-Mirsky Theorem, \(\hat{X}_k\) is the best rank-\(k\) approximation to \(X\) in Frobenius norm! Let’s visualize the 2D PCA projection of Iris alongside the Scree Plot (cumulative variance explained):
